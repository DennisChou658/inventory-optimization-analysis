# Inventory Optimization Analysis

This project explores inventory optimization using simulated supply chain data, with a focus on balancing service levels, inventory cost, and operational efficiency.

The analysis looks at demand variability, safety stock, reorder points, stockout risk, and inventory performance to support practical supply chain decision making.

## Project Focus

Demand Variability

Safety Stock

Reorder Point Analysis

Stockout Risk

Inventory Turnover

Operational Efficiency

Supply Chain Data Visualization

## Tools

Python

Pandas

NumPy

Matplotlib

## Project Goals

Analyze demand patterns and inventory requirements.

Calculate safety stock based on demand variability.

Estimate reorder points using demand and lead time assumptions.

Identify products with higher stockout risk.

Evaluate inventory efficiency and turnover.

Visualize supply chain data to support operational decisions.

## Data

This project uses simulated supply chain and inventory data only.

No proprietary or confidential supplier, purchasing, logistics, pricing, customer, or company data is used.
